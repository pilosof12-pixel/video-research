# Lottie assets
Put `.json` / `.lottie` files here (no files are shipped). Load in Remotion with `@remotion/lottie` (`<IconPop lottie={data} />`) or in HyperFrames via the Lottie adapter.

Free sources (check each asset's license; keep a note in LICENSES.md):
- LottieFiles free animations: https://lottiefiles.com/free-animations (Lottie Simple License)
- Google Noto animated emoji: https://googlefonts.github.io/noto-emoji-animation/ (Lottie JSON, CC BY 4.0)
- Fallback static icons: Lucide https://lucide.dev (ISC), Iconify https://iconify.design (per-set licenses)
